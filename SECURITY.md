# Security policy

CAD-MAX is in an early bootstrap phase and must not be used for production drawing
automation.

Report suspected vulnerabilities privately through GitHub's security advisory flow
for ling5477/CAD-MAX. Do not include credentials, proprietary drawings, customer data,
or exploit payloads in public issues.

The active security model, trust boundaries, defaults, and contributor requirements
are documented in [docs/SECURITY.md](docs/SECURITY.md).
